## 一、项目概述

### 核心目标

| 模块 | 功能 | 优先级 |
|------|------|--------|
| 导航中台 | 链接分类 + 卡片 + 环境标记 + 失效检测 | P0 |
| TIL 知识墙 | Markdown + 标签 + 项目绑定 + 归档 | P0 |
| Mock API 工厂 | Schema + 动态接口 + 请求日志 + Postman 导出 | P1 |
| 基础工具集 | Base64 / 时间戳 / JSON 格式化（纯前端） | P1 |
| 团队环境中心 | 环境管理 + 快速切换 | P2 |
| 项目资产大盘 | 数据统计 + 趋势图表 | P1 |
| 操作日志 | 操作记录追溯 | P2 |

### 不做（MVP 阶段）

- 复杂用户体系（仅保留简单登录拦截）
- 评论私信、推送通知
- 第三方登录
- 移动端适配

## 八、风险与应对

| 风险 | 影响 | 应对措施 |

| 后端接口延期 | 前端等待 | 前端先用 Mock 数据开发 |

## 九、代码规范

### 前端

- 组件名：大驼峰（PascalCase）
- 文件命名：小驼峰（camelCase）
- 使用 ESLint + Prettier
- 注释：函数注释、复杂逻辑注释

### 后端

- 遵循 PEP8 规范
- 使用 Black 格式化代码
- 函数注释使用 Google Style
- API 统一响应格式：
  ```json
  {
    "code": 200,
    "message": "success",
    "data": {}
  }
  ```
